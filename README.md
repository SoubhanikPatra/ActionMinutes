# ActionMinutes

ActionMinutes converts meeting recordings into clear decisions, owners, and deadlines — with human review and confidence scoring.

## MVP Scope
- Upload meeting audio
- Speech-to-text transcription
- Decision & action-item extraction
- Confidence-based review
- Manual confirmation before export

## Tech Stack
- FastAPI (Python backend)
- Next.js + Tailwind (frontend)
- Whisper ASR
- LLM-based information extraction
